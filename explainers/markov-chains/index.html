Markov chains

If tomorrow's weather depends only on today's, you can forecast a week ahead by multiplying a small table by itself. Do it long enough and something odd happens: the forecast stops depending on today at all.

How it works

Memoryless. A Markov chain is a set of states and, for each one, the chances of moving to each state next. Only the present matters: how the weather got to be rainy doesn't change tomorrow's odds. The table is the whole model, and every row adds up to 1.

Forecasting. If today is sunny, tomorrow's chances are just the sunny row. For the day after, average the rows by those chances, which is multiplying the distribution by the table once more. A forecast n days out is the table multiplied by itself n times.

The long run. Each multiplication blends the rows a bit more, and after a couple of weeks every starting point gives the same answer: the stationary distribution, the mix that one more step leaves unchanged. It's also how often each kind of day turns up over a long stretch, which is why the simulated days' counts land on it. This holds for any chain where every state can reach every other and the chain doesn't cycle in lockstep.

Try it. Make sunny days very sticky and watch both the long-run mix and how many days it takes to forget today.

Everywhere. PageRank is the stationary distribution of a random web surfer. Text predictors used to be Markov chains over words, and language models are vastly richer versions of the same question: what comes next, given what came before. Markov chain Monte Carlo samples from hard distributions by designing a chain whose long run is the distribution you want.

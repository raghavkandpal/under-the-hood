Convolution & image filters

Blur, sharpen, edge detection, and the first layer of every image-recognition network are all the same operation. Slide a small grid of numbers (a kernel) over the image, and at each spot multiply and add. Hover over the image to watch it happen for a single pixel.

How it works

Multiply, add, move. For each output pixel, lay the kernel over the input pixel and its neighbours, multiply each pair, and add the products. That sum is the new pixel. Repeat for every position.

What the numbers mean. All positive and summing to 1 averages the neighbours, which blurs. A big centre minus the neighbours exaggerates differences, which sharpens. Negative on one side and positive on the other measures how fast brightness changes, which finds edges. Sobel x lights up vertical edges and Sobel y horizontal ones. Flat regions give 0 for any edge kernel, so they go grey in the output.

Why neural networks love it. A convolutional neural network (CNN) learns its kernels instead of using hand-made ones. Early layers end up learning edge and colour detectors much like these, and later layers combine them into textures, parts and objects. Because the same small kernel slides over the whole image, a cat in the corner is detected the same way as a cat in the middle, using few parameters.

Processing uses brightness only, with clamped borders. Signed edge outputs are drawn with grey = 0, white = positive, black = negative. Strictly this is cross-correlation (no kernel flip), which is what image libraries and deep-learning frameworks call "convolution".

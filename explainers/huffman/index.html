Huffman coding

ASCII spends 8 bits on every character. Huffman gives common characters short codes and rare ones long codes, and still guarantees the bit stream decodes with no ambiguity.

The rule, in one line

Take the two lightest trees and join them under a new parent whose weight is their sum. Repeat until one tree is left. Going left adds a 0 and going right adds a 1. Every character sits at a leaf, so no code can be the prefix of another, and that's why the stream needs no separators.

Try this

  • Type aaaaaaaab. One character dominates, so it gets a 1-bit code.
  • Type the alphabet once, all different. Equal frequencies produce codes of almost equal length, so the savings come only from having fewer than 256 symbols.
  • Paste a paragraph of English. It usually lands around 4–4.5 bits per character, close to its entropy.

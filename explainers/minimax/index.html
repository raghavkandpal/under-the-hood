Game trees and minimax

To play a game perfectly, imagine every move, every reply, and every reply to that, all the way to the end. Then assume your opponent is as clever as you. That's minimax, and alpha-beta pruning lets it skip most of the work.

How it works

The game tree. Every position branches into one child per legal move, down to positions where someone has won or the board is full. Tic-tac-toe's full tree has 549,946 positions. Score the end positions: +1 if X won, −1 if O won, 0 for a draw.

Minimax. Work back up from the ends. In a position where X is to move, X picks the child with the highest score; where O moves, O picks the lowest. Each position's score is what happens with perfect play from there. The empty board scores 0: neither side can force a win, so a perfect player never loses at tic-tac-toe. The computer here searches to the end before every move, and preferring quicker wins and slower losses keeps it from dawdling.

Alpha-beta pruning. Suppose X has already found a move that guarantees a draw. Exploring another move, X sees O has a reply that wins. X doesn't need to see O's other replies: that move is already worse than the draw, and O would never let it be better. Alpha and beta are the best scores each side is already guaranteed; once they cross, the rest of that branch can't matter and is skipped. The answer is identical, and from the empty board it looks at 20,866 positions instead of 549,946.

Try it. Start a game and compare the two position counts after the computer's first reply, then after a few more moves as the tree shrinks.

Bigger games. Chess has around 10⁴⁴ legal positions, far too many to search to the end. Engines search a few moves ahead, score the positions there with a heuristic (material, mobility, king safety, or a neural network), and rely on good move ordering, because alpha-beta prunes most when the best move is tried first. Go programs replaced exhaustive search with sampling (Monte Carlo tree search) guided by learned evaluations.

Simplified: no transposition table, so positions reached by different move orders are searched again; with one, tic-tac-toe has only 5,478 distinct positions.

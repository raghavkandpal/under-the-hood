The KV cache

A language model writes one token at a time, and each new token has to look back at every token before it. Done naively, writing token 1,000 means reprocessing the 999 before it, every single step. One cache fixes that. It's why a chatbot pauses before the first word and then streams quickly, and why long conversations use so much GPU memory.

How it works

Attention looks back. In every layer, each token makes a query (“what am I looking for?”), a key (“what do I contain?”) and a value (“what do I pass on?”). The newest token compares its query with every earlier key and takes a weighted mix of their values. See attention.

Old keys and values never change. The model is causal: earlier tokens can't see later ones, so token 5's key is the same whether we're generating token 6 or token 600. Recomputing it every step is pure waste. Store it once, and each new step only computes keys and values for the one new token. The work per step goes from growing with the length to constant, and total work from quadratic to linear. The outputs are bit-for-bit identical.

Prefill vs decode. The prompt is processed in one big parallel pass that fills the cache, which is the pause before the first word. Then decoding adds one token at a time, reading the whole cache each step, so speed is limited by memory bandwidth.

The memory bill grows with layers × heads × context length. Long contexts and many simultaneous users quickly need more memory for caches than for the model itself. Hence the tricks: grouped-query attention shares each key/value head among several query heads (compare the two 8B shapes), the cache can be quantized to 8 bits, and servers page it in blocks like virtual memory (vLLM's PagedAttention). Prompt caching reuses the cache for a shared prefix, such as a long system prompt, across requests.

Model shapes are illustrative of their size class. Attention scores still compare against every past key, which also grows with length, but that's a cheap dot product compared with recomputing every layer for every past token.

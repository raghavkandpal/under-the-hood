What to remember

A p-value answers one narrow question: if there were no real difference, how surprising would data like this be? Below 0.05 means "fewer than 1 in 20 no-difference worlds look this extreme". It's not the probability that B is better.

Small effects need big samples. Detecting a 10% → 11% change takes roughly four times as many visitors as 10% → 12%, because the noise shrinks only with √n. Run the experiment at 1,000 visitors with a true 2-point lift and press 🎲 a few times. Sometimes B "loses".

Decide the sample size first, then look once. Every peek is another chance for noise to cross the line, so stopping at the first significant result can multiply false positives several times over. If you must monitor continuously, use methods built for it: sequential tests, alpha spending, or Bayesian approaches with appropriate priors.

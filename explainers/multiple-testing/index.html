Multiple testing

Test twenty ideas that do nothing at p < 0.05 and, about two times in three, at least one of them “wins”. The more questions you ask of the same data, the more answers come from luck.

  • false win
  • missed
  • no effect
1,000 runs

How it works

One test. A p-value below 0.05 means: if the idea did nothing, data this extreme would turn up less than 5% of the time. So a test of a useless idea still “wins” 1 time in 20. That's the price of one test, and it's usually acceptable.

Many tests. Each extra test buys another 5% lottery ticket. With 20 independent tests of nothing, the chance that none wins is 0.95²⁰ ≈ 36%, so 64% of the time you get at least one false discovery. Testing many metrics, many segments (“it worked for users in Ohio on Tuesdays”), many variants, or peeking at a running A/B test all count. So does trying analyses until one comes out significant, which is p-hacking.

Try it. With 20 tests and no real effects, run 1,000 experiments without a correction, then with each correction. Then add 20% real effects and compare how many each one finds.

Bonferroni. Divide the threshold by the number of tests: with 20, a win needs p < 0.0025. That keeps the chance of any false win under 5%, the family-wise error rate. It's simple and safe, but strict: with 50 tests, a real effect that one test alone would catch 85% of the time is caught well under half the time.

Benjamini–Hochberg (BH). Sort the p-values. The smallest must beat α/m, the second 2α/m, and so on up a rising line. Find the last p-value under the line, and everything before it wins. This controls the false discovery rate: on average, at most 5% of your wins are flukes. You accept the odd false win in exchange for finding many more real ones, which suits screening many candidates for follow-up.

Which to use. When one false claim is costly (a drug approval, a headline result), control the family-wise rate. When you're picking candidates to test again, control the false discovery rate. Either way, decide how many tests you're running before you look, and report all of them. A correction can't count tests you didn't admit to.

Simplified: tests are independent z-tests and every real effect is the same size. Benjamini–Hochberg also holds for positively correlated tests; Holm's method is a uniformly stronger version of Bonferroni.

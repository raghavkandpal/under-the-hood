Internet routing

No router on the internet has a map of the whole thing. Each one only talks to its neighbours, swapping notes like “I can reach X in 3 hops”, and from that gossip alone every packet finds a short path. Until a cable is cut, and bad news turns out to travel much more slowly than good news.

Router 's table

How it works

Distance vector. Every router keeps a table: for each destination, the cost and which neighbour to hand the packet to. Periodically it sends its costs to its neighbours. Hearing that neighbour N can reach X at cost c, over a link costing ℓ, it knows a route to X at c + ℓ via N, and keeps the cheapest. That's the Bellman-Ford algorithm, spread across many machines. News spreads one hop per exchange. Press “Exchange once” and watch the tables fill outward.

Click any link to cut or restore it. The packet path (thick) follows each router's “via” pointer hop by hop. No one router knows the whole route.

Bad news travels slowly. Cut C–E and step through. C's neighbours still advertise routes to E that secretly went through C, so for a few rounds the routers point at each other and packets loop until their TTL expires. Then the real detour via B wins.

Count to infinity. Now cut E and F off completely. Every router still hears “E is reachable” from a neighbour whose route was really learned from it, so the cost creeps up a little each round and never settles. RIP caps “infinity” at 16 hops so the counting at least ends. Split horizon means never advertising a route back to the neighbour you learned it from, and the poisoned reverse variant advertises it as unreachable instead. That cures the loop between two routers, but here the stale route circles A → B → C → D, so it only shortens the count. Fixing that for good takes a different design.

Link state (OSPF, IS-IS, inside a company or ISP) takes the other approach: every router floods a description of its own links to everyone, so all have the full map and run Dijkstra. Between the internet's ~75,000 networks, BGP uses path vectors, advertising the whole list of networks a route passes through. That lets it spot loops instantly and apply business policy, such as preferring a route because it's cheaper rather than shorter.

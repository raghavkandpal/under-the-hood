Strongly connected components and 2-SAT

In a directed graph, two nodes belong together when each can reach the other. Finding those groups takes two depth-first passes, and the same groups decide whether a pile of "either this or that" rules can all hold at once.

How it works

Groups. A strongly connected component is a set of nodes that all reach each other. This graph has 8 nodes and 11 arrows, and falls into 4 groups. Collapse each group into one node and the groups form a graph with no cycle, since a cycle would have merged them. That is the condensation, and it can be put in order with a topological sort.

Two passes. Kosaraju–Sharir first runs a depth-first search on the reversed graph and notes the order in which nodes finish. Reading that finishing order backwards gives the start order for pass 2: a depth-first search on the original graph, starting from the first node in the list that is still unvisited. Each time pass 2 starts a new search, everything it reaches is one whole group, because the last node to finish in the reversed graph sits in a group with no arrows leaving it, so a search from there cannot leak into a group that is still waiting.

Try it: switch pass 2 to node order. A search from node 0 reaches nodes 6 and 7, which cannot get back to 0, so one group swallows all 8 nodes and the count of groups that are not strongly connected goes to 1.

The cost. Each pass looks at every arrow once, so on this graph the two passes make 22 checks, twice 11, in either order. That is O(nodes + arrows) overall.

2-SAT. Each rule is "this or that", such as a ∨ ¬b. It says that if a is false then ¬b must hold, and if b is true then a must hold, so a clause becomes two arrows between the literals, ¬a ⇒ ¬b and b ⇒ a. The formula (a ∨ ¬b) ∧ (¬a ∨ b) ∧ (¬a ∨ ¬b) ∧ (a ∨ ¬c) has 4 clauses, so 8 arrows over 6 literals.

Reading the answer. If a literal and its negation share a group, each implies the other and no assignment exists. Otherwise the formula is satisfiable. Pass 2 finds groups with the end of the condensation first, so set a variable true when its literal's group was found before its negation's. The worked formula comes out as a, b and c all false, and the page checks that against all 4 clauses. Adding (a ∨ b) makes 10 arrows, and a and ¬a land in one group: a ⇒ ¬b ⇒ ¬a ⇒ b ⇒ a.

Checked by brute force. The Random formulas have 5 variables and 4 to 12 clauses. For each of the seeds 1 to 200, the verdict from groups agrees with trying all 32 assignments, and 165 of the 200 are satisfiable. For general SAT with more literals per clause, see constraint solving.

Simplified: recursive depth-first search on small graphs, and the 8-node graph and the formulas are made up for this page. Tarjan's one-pass algorithm finds the same groups.

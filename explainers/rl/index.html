Reinforcement learning

Nobody tells this agent the way to the goal. It wanders, gets rewards and penalties, and slowly learns which moves pay off. The same idea, scaled up enormously, taught programs to play Go and is used to tune language models.

How Q-learning works

The setup. At each step the agent is in a state (a cell), picks an action (a direction), and gets a reward: −1 per step to encourage speed, +20 for the goal, −20 for a pit. Its job is to maximise total reward.

Q-values. For every cell and action it keeps a guess, Q(s, a), of "how much reward I'll collect from here if I do this, then play well". After each move it nudges the guess toward what just happened: Q ← Q + α · (reward + γ · best Q of the next cell − Q). Good news ripples backward from the goal, one step per visit. Watch the green spread out from it.

Explore vs exploit. With probability ε the agent moves at random instead of taking its best-known move. Too little and it locks onto the first route it finds. Too much and it keeps falling off the cliff while it learns. Set ε to 0 on the maze and it may never find the goal.

γ is patience. In "Near vs far reward", a +5 prize sits 3 steps away and a +20 prize 11 steps away. Press "Show the optimal answer": at γ = 0.6 future rewards fade so fast that the near prize really is best, and at γ = 0.95 the far one is.

The exploration trap. Now train at γ = 0.95. The learner almost always settles for the near prize anyway. It found +5 early, its random moves rarely carry it 11 steps the other way, and so it never learns the far prize exists. Tick Optimistic start and train again. Every untried move now looks promising until proven otherwise, so the agent systematically checks the whole map and finds the better goal. Deciding how much to explore is one of the hard, open problems in RL.

Slipperiness. When moves sometimes slide sideways, the optimal plan on the cliff map changes. It's worth a longer path away from the edge to avoid sliding in. "Show the optimal answer" uses value iteration, which can plan exactly because it's given the rules. Q-learning has to discover them by trial and error.

Tabular Q-learning (Watkins, 1989) with ε-greedy exploration. Deep RL replaces the table with a neural network so it can handle huge state spaces like game screens.
